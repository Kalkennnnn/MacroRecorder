# Mouse Recorder

Небольшая программа для Windows, которая записывает действия мыши и воспроизводит их. Подходит для автоматизации однообразных операций: записал один раз, потом повторяй сколько нужно.


## Возможности

- Запись движений мыши, кликов (левая, правая, средняя кнопки) и прокрутки колёсика
- Воспроизведение записанного макроса с сохранением исходных пауз
- Зацикливание воспроизведения
- Сохранение макроса в JSON-файл и загрузка из него
- Глобальные горячие клавиши, которые работают, даже когда окно программы свёрнуто
- Журнал событий в окне программы

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| F8 | Начать / остановить запись |
| F10 | Начать / остановить воспроизведение |
| Esc | Выход из программы |
